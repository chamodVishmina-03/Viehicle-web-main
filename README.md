# AutoCare Web – Vehicle Service & Repair Management (React + Vite + Tailwind 4)

```bash
npm install
npm run dev     # http://localhost:3000
```
Set the API URL in `.env`:  `VITE_API_BASE_URL=http://localhost:5000/api/v1`

Pages: Login/Register, Dashboard, Vehicles (list/add/detail), Book Service (AI diagnosis), My Services, Assignments (mechanic), Job Detail (status, parts & costs, timeline), Admin Dashboard, Admin Users.
